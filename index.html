Vanilla ES6+ JavaScript Modules — Straight From a CDN

Small, dependency-free JS modules for static sites — DOM and fetch helpers, cookies, WhatsApp QR login, a slippy map without Leaflet, heatmaps and coverage grids, and a glTF/GLB 3D viewer without Three.js. Import what you need directly from jsDelivr; no npm install, no bundler.

What's Actually In It

Zero Build, Zero Install

Import modules straight from jsDelivr's CDN with a <script type="module"> tag. No npm install, no bundler config, no build step.

Fetch Wrappers, Not a Framework

getJSON, postJSON, putJSON, deleteJSON — thin wrappers over the native Fetch API with a consistent {status, data} callback.

DOM Helpers Without the Boilerplate

onClick, setInner, getValue, serializeForm, show/hide — skip repetitive document.getElementById calls. Pair with debounce.js for search-as-you-type.

WhatsApp QR + OTP Login

auth.js and stp.js give you a ready-made WhatsAuth QR-code and OTP login flow, including Google Sign-In.

Cookies, Storage, URLs & Validation

cookie.js, storage.js, url.js, and validate.js cover session cookies, localStorage/sessionStorage (with optional expiry), query strings, and input sanitization.

Import Only What You Use

Every module is a separate CDN file — .../lib@version/cookie.js — so your page only loads the code it actually needs.

Notifications, No Dependency

toast.js shows dismissable notifications with zero external libraries — an alternative to pulling in SweetAlert2 just for a message.

Read GeoJSON

geo.js loads GeoJSON from a URL or a local file, validates it, and always hands back a FeatureCollection — plus getBBox, getCenter, and getPropertyKeys for feeding a map or a table.

Maps Without a Map Library

map.js is a slippy map written from scratch — tile basemap, GeoJSON drawn as SVG, pan, pinch-zoom, popups, click-to-pick coordinates, named layers, feature labels, hover tooltips, dashed lines, satellite/hybrid basemaps you can switch without redrawing, and a canvas renderer for thousands of lines — in about 13 KB gzipped, with no Leaflet and no CSS file to link.

Markers, Routes & Measurements

Optional add-ons of 1–8 KB each: draggable pin and icon markers (mapmarker.js), a scale bar, locate-me, live tracking, basemap switchers (radio list or Google-Maps-style picture cards), layer switchers, cursor coordinates, a right-click / long-press context menu for GIS actions, and fullscreen (mapcontrol.js), drawing and editing points, lines and polygons as GeoJSON (mapdraw.js), address search and reverse geocoding (mapsearch.js), offline basemaps from a single PMTiles file (mapoffline.js), true-to-scale 3D models placed on the map (mapmodel.js), distance/area measuring, rotated image overlays and PNG export (maptools.js), clustering for very large point sets (mapcluster.js), density heatmaps and nPerf-style square/hex coverage grids (mapheat.js), distance, area and point-in-polygon (geomeasure.js), and shortest routes computed in the browser from your own GeoJSON lines (georoute.js).

3D Models Without Three.js

model3d.js shows glTF/GLB models on WebGL2 (with a WebGL1 fallback) using its own binary parser, matrices and shaders — orbit, pinch-zoom, click a part, recolor, hide or move it from code, with skinned characters and Draco-compressed models — in about 16 KB gzipped. model3dtools.js adds HTML labels pinned to the model, translate/rotate/scale gizmos, glTF animation playback, exploded views, cross-sections for interactive learning material, a “View in AR” button (Android Scene Viewer, iOS Quick Look), and re-export to a new .glb.

Quick Start Example

Get started with CrootJS in just a few lines of code. Import from CDN and start building dynamic websites immediately.

main.js 
// Import CrootJS functions from CDN
import { setInner, onClick, getValue }
from "https://cdn.jsdelivr.net/gh/crootjs/lib@0.0.28/element.min.js";
import { postJSON } from "https://cdn.jsdelivr.net/gh/crootjs/lib@0.0.28/api.min.js";

// Configure backend URL
const urlBackend = "https://api.example.com";

// Handle login button click
onClick("loginBtn", () => {
  // Get form values
  const email = getValue("email");
  const password = getValue("password");

  // Send login request
  postJSON(`${urlBackend}/login`, { email, password }, (response) => {
    // Handle response
    if (response.status === 200) {
      setInner("demo", "Login successful!");
    }
  });
});

Building With an AI Coding Agent?

CrootJS requires separating HTML, CSS, and JS into their own files, with JS loaded as type="module" — no inline <script>/<style>, no onclick. Drop CLAUDE.md into your project root so Claude Code (or any agent that reads a root instructions file) follows this automatically.

terminal 
curl -o CLAUDE.md https://raw.githubusercontent.com/crootjs/lib/main/CLAUDE.md

Agents that read docs instead of guessing can start from llms.txt (one-page summary of every module and signature), llms-full.txt (all module docs in one file), or any doc page as plain Markdown — e.g. /docs/map.md, /docs/model3d.md.
