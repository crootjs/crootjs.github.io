Vanilla ES6+ JavaScript Modules — Straight From a CDN

A set of small, dependency-free JS modules for static sites — DOM helpers, fetch wrappers, cookies, URL utilities, and a WhatsApp QR login flow. Import what you need directly from jsDelivr; no npm install, no bundler.

What's Actually In It

Zero Build, Zero Install

Import modules straight from jsDelivr's CDN with a <script type="module"> tag. No npm install, no bundler config, no build step.

Fetch Wrappers, Not a Framework

getJSON, postJSON, putJSON, deleteJSON — thin wrappers over the native Fetch API with a consistent {status, data} callback.

DOM Helpers Without the Boilerplate

onClick, setInner, getValue, show/hide — skip repetitive document.getElementById calls. Pair with debounce.js for search-as-you-type.

WhatsApp QR + OTP Login

auth.js and stp.js give you a ready-made WhatsAuth QR-code and OTP login flow, including Google Sign-In.

Cookies, Storage, URLs & Validation

cookie.js, storage.js, url.js, and validate.js cover session cookies, localStorage/sessionStorage (with optional expiry), query strings, and input sanitization.

Import Only What You Use

Every module is a separate CDN file — .../lib@version/cookie.js — so your page only loads the code it actually needs.

Quick Start Example

Get started with CrootJS in just a few lines of code. Import from CDN and start building dynamic websites immediately.

main.js 
// Import CrootJS functions from CDN
import { setInner, onClick, getValue }
from "https://cdn.jsdelivr.net/gh/crootjs/lib@0.0.7/element.min.js";
import { postJSON } from "https://cdn.jsdelivr.net/gh/crootjs/lib@0.0.7/api.min.js";

// Configure backend URL
const urlBackend = "https://api.example.com";

// Handle login button click
onClick("loginBtn", () => {
  // Get form values
  const email = getValue("email");
  const password = getValue("password");

  // Send login request
  postJSON(`${urlBackend}/login`, { email, password }, (response) => {
    // Handle response
    if (response.status === 200) {
      setInner("demo", "Login successful!");
    }
  });
});
